按钮规则：「开通1年」会从今天重新计算 365 天；「免费加1年」只给你指定的少数学生，现有到期日 +365 天；「续费1年」用于学生付款后，到期日 +365 天。免费与付费续费会分别记录在后台 Audit Log。为避免误点，执行前会先核对资料，并要求输入该学生的 Student ID 二次确认。

＋ 新增学生

建立 Supabase 登录账号、Student ID、学生资料，并一次开通 SCORE-A 课程权限。

建立后系统会自动产生下一个 Student ID（例如 SCORE-A00004）、状态设为 ACTIVE，并根据 365 / 730 天自动计算到期日期。临时密码不会保存或显示在学生名单，请先确认你已经记录好密码再建立。
